# CrimeGraph

CrimeGraph is a responsive web application for helping Station House Officers explore and manage crime data through an interactive dashboard.

## Live Demo

- [Open the CrimeGraph dashboard](https://crimegraph-ai-seven.vercel.app/dashboard)
- [Read the in-app documentation](https://crimegraph-ai-seven.vercel.app/docs)

## Getting Started

Install the dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

The main dashboard is available at [http://localhost:3000/dashboard](http://localhost:3000/dashboard).

For the complete setup, production implementation, security, and deployment checklist, see the [Project Setup and Completion Guide](PROJECT_SETUP_AND_COMPLETION_GUIDE.md).

## Available Scripts

```bash
npm run dev      # Start the development server
npm run lint     # Check the project for lint errors
npm run build    # Create a production build
npm run start    # Start the production server
```

## Deploy on Vercel

The project is configured for [Vercel](https://vercel.com). To deploy a new version, import this repository into Vercel or run:

```bash
npx vercel
```

The current production deployment is available at:

https://crimegraph-ai-seven.vercel.app/dashboard
